# Jadoo landing page

A responsive travel landing page based on the supplied Jadoo design, built with React, Vite, and Tailwind CSS 4.

## Run locally

Requires Node.js 22.12 or newer.

```sh
npm ci
npm run dev
```

## Features

- Responsive layout with sticky navigation.
- Hotel and flight preview dialogs, destination details, and account dialogs.
- Interactive testimonials, demo popup, trip-save toggle, and newsletter preview.

This is a frontend demonstration. Live search, booking, authentication, and email delivery are not connected. English is the only available language. Controls without supplied content or real URLs remain inactive.

## Build and deploy

```sh
npm run build
npm run preview
```

Deploy the generated `dist` folder to a static host. No environment variables are required.

Responsive layouts and interactions were checked in Microsoft Edge at widths from 320 to 1920 pixels.
